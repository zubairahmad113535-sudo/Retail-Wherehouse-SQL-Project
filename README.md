# Retail Warehouse SQL Analysis

## 📌 Project Overview

This project focuses on analyzing a **Retail Warehouse database using MySQL**. The database was designed using multiple related tables to represent customers, stores, suppliers, products, categories, orders, payments, shipments, promotions, and returns.

The main objective of this project is to use **SQL queries to answer real-world business questions** related to sales, customers, products, orders, and business performance.

## 🗄️ Database Schema

The project contains the following tables:

- Customers
- Stores
- Suppliers
- Categories
- Promotions
- Products
- Orders
- Order Items
- Payments
- Shipments
- Returns

The tables are connected using **Primary Keys and Foreign Keys** to create a relational database structure.

## 🎯 Business Questions

I created SQL queries to answer **20 business questions**, including:

1. What is the total number of customers?
2. What are the unique customer locations?
3. Which products are priced above 100?
4. What are the 10 most expensive products?
5. What is the total number of orders?
6. What are the total sales?
7. What is the average order value?
8. What are the total sales by product?
9. Which orders generated sales above 10,000?
10. Which customers placed orders and when?
11. Which category does each product belong to?
12. What are the top 10 best-selling products?
13. Which customers placed more than one order?
14. What are the monthly sales?
15. Who are the highest-spending customers?
16. Which products have sales above the average product sales?
17. Which customers are repeat customers?
18. What are the top 3 products in each category?
19. What is the second-highest order value?
20. What percentage of total sales does each product contribute?
